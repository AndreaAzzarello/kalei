# Test samples

Where the files that tests read live. Rules (CLAUDE.md, 1.0 spec):

- Every Format has samples: **valid**, **truncated/corrupt**, **wrong extension**, and one **large** file.
- Small samples are committed, one folder per Format: `tests/samples/<format>/`, with names that say what they are (`valid.png`, `truncated.png`, `png-named-jpg.jpg`).
- **Large and huge samples are generated by the tests**, never committed, into `tests/samples/generated/` (ignored by git) or a temporary folder. The generator is part of the test.
- Samples hold no personal data and no real paths or names. Each sample's origin and licence are noted in a `README.md` next to it when it is not generated by us.
- Tests check the result and the failure (exact error code), as in the spec's testing decisions.
