# Image samples (ticket 06)

Folders `png`, `jpg`, `gif`, `webp`, `tiff`, `bmp`, `ico`, `avif`, `heic`. Each holds `valid.*`, `truncated.*` (the signature cut short, so the header stage cannot match) and `<format>-named-<other>.<ext>` (real content, wrong extension).

- Origin: generated by us from a 2×2 (ICO: 16×16) solid-colour image with Pillow, one call to `Image.save` per Format. No third-party content, no personal data. Licence: CC0.
- `heic/valid-header.heic` is hand-made: one `ftyp` box (`heic`, compatible `mif1`, `heic`) and no image data, because Pillow has no HEVC encoder. It exercises the header stage only, not a decoder.
- Large files are never committed: the tests generate them as synthetic streams (see `HeaderReaderAndRobustnessTests`).
